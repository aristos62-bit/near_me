Σύνοψη (EL)

Privacy-first / Local-first: Το πλήρες προφίλ ζει μόνο στη συσκευή σου (Drift/SQLite). Στο cloud ανεβαίνει μόνο το δημόσιο στιγμιότυπο που επιλέγεις ρητά, και μόνο όσο το κρατάς δημοσιευμένο.

1. Data we collect — Τι συλλέγουμε

  • Location — ρυθμιζόμενη ακρίβεια που επιλέγεις: Πόλη / Γειτονιά / Δρόμος (~150m) / Κρυφό. Αποθηκεύεται ως GeoHash 3 / 5 / 7 χαρακτήρων αντίστοιχα (hidden = διαγράφεται). Ποτέ δεν αποθηκεύεται δημόσια η ακριβής GPS συντεταγμένη (lat/lng). Επιλογή στο Privacy Editor → Ακρίβεια Τοποθεσίας (privacy_editor_screen.dart:201, functions/src/index.ts:787-800). Για την εύρεση ονόματος πόλης/χώρας χρησιμοποιείται η υπηρεσία geocoding της συσκευής (Google/Apple) — placemarkFromCoordinates — και Nominatim autocomplete όπου χρειάζεται.
  • City/Country (text): πόλη/χώρα που συμπληρώνεις ή προκύπτει από reverse geocode.
  • Profile: ψευδώνυμο, έτος γέννησης (gate 18+), φύλο, ενδιαφέροντα, αναζητώ, bio — τοπικά στο Drift, δημόσιο snapshot μόνο για τα πεδία που έχεις ενεργοποιήσει.
  • Photos/Avatars: avatars/{uid}/profile.jpg, photos/{uid}/{n}.jpg (έως 5, 5MB), chat_media/{chatId}/{msgId}.jpg/.mp4/.m4a (50MB), group_avatars/{chatId}/ — μέχρι να τα διαγράψεις. EXIF (GPS) αφαιρείται πριν το upload.
  • Έλεγχος ακατάλληλου περιεχομένου: Κάθε φωτογραφία/avatar/chat image (& thumbnail video) ελέγχεται αυτοματοποιημένα με Google Vision SafeSearch στο eu-vision.googleapis.com (EU) για adult/racy/violence. Απόρριψη → άμεση διαγραφή + προσωρινό κατέβασμα προφίλ από αναζήτηση. Δεν γίνεται ανθρώπινη επισκόπηση παρά μόνο σε αναφορά.
  • Messages: κρυπτογράφηση AES-256-GCM client-side (encryption_utils.dart:25), IV 12 bytes. Αποθήκευση chats/{chatId}/messages/{msgId} μέχρι λήξη/διαγραφή.
  • FCM token: users/{uid}/fcm_tokens/{tokenId} για ειδοποιήσεις.
  • Crash logs: Firebase Crashlytics — OFF by default, μόνο αν το ενεργοποιήσεις σε Settings → Diagnostics → Crash Reports. Σε OFF γίνεται deleteUnsentReports(). Native flag firebase_crashlytics_collection_enabled=false (Android AndroidManifest.xml:62, iOS Info.plist: FirebaseCrashlyticsCollectionEnabled=false).
  • Presence: isOnline/lastSeen — heartbeat 60s.

2. Legal basis — Νομική βάση (GDPR Art.6)

Consent Art.6(1)(a) — κάθε πεδίο έχει ξεχωριστό toggle στο Privacy Editor. Μπορείς να αποσύρεις τη συγκατάθεση με Unpublish ή απενεργοποίηση toggle. Για crash logs: συγκατάθεση (opt-in). Δεν γίνεται profiling/automated decision-making.

3. Retention — Διάρκεια τήρησης

Μέχρι τη διαγραφή λογαριασμού (Settings → Διαγραφή Λογαριασμού → CF deleteUserData functions/src/index.ts:563 διαγράφει 10+ buckets: avatars, photos, requests, chats/messages, public/profile, status, privacy/settings, blocked, rateLimits/search, fcm_tokens + Storage). Μηνύματα ομαδικών με messageExpiry διαγράφονται αυτόματα (CF expireStaleMessages κάθε 5'). Αιτήματα λήγουν σε 48h (expireStaleRequests).

4. Sharing

Δεν πουλάμε δεδομένα. Πρόσβαση έχουν μόνο: εσύ, οι χρήστες στους οποίους εμφανίζεσαι ως isVisible==true και πληρούν τα φίλτρα, και η Google Cloud (processor) στο πλαίσιο Firebase Hosting/Firestore/Storage/Functions σε EU.

5. Your rights — Δικαιώματα (GDPR Art.12-22)

  • Access: βλέπεις τοπικά όλο το προφίλ (Drift) και το δημόσιο snapshot.
  • Rectification: Profile Editor.
  • Erasure: Settings → Διαγραφή Λογαριασμού.
  • Restriction: Unpublish (toggle ορατότητας).
  • Objection: Block user.
  • Portability: κατόπιν αιτήματος στο soc.near.app@gmail.com (εξαγωγή Drift — roadmap).
  • Withdraw consent: ανά πάσα στιγμή από Privacy Editor.

6. Security

TLS 1.3 σε transit, AES-256-GCM σε chat, FLAG_SECURE screenshot prevention (opt-in), biometric lock + auto-lock 1-30', room για chat keys σε flutter_secure_storage. Security Rules 7 helpers + 21 indexes.

7. Children

Υπηρεσία 18+ μόνο (έλεγχος age >=18 στο publish firestore.rules:87).

8. Permissions — γιατί ζητάμε

  • Location (WhenInUse) — εύρεση κοντινών προφίλ, μόνο με συγκατάθεση.
  • Camera / Photo Library — avatar/φωτογραφίες/chat images.
  • Microphone — φωνητικά μηνύματα (~60s).
  • Notifications — FCM για μηνύματα/αιτήματα.
